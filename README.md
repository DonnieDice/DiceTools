# DiceTools

A developer and debugging toolkit for World of Warcraft.

## Features

- **Pet Journal Inspector** — Dump full pet stats including health, power, speed, and rarity
- **Quest Tools** — Look up quest details by name/ID, list available quests in your zone
- **Zone Explorer** — Get zone details by name, list all continents and their zones
- **XP & Level Details** — Player level, current XP, rested XP, and XP to next level
- **Faction Info** — Renown faction levels and friendship reputation status
- **TradePost Tracker** — List current TradePost activities and completion status
- **API Explorer** — Call any global WoW API function by name and inspect the result
- **Utility Commands** — Reload UI, clear all chat windows, check game version

## Slash Commands

| Command | Description |
|---------|-------------|
| `/dt` | List all commands |
| `/info` | Show game version |
| `/rl` | Reload UI |
| `/clear` | Clear all chat windows |
| `/petinfo` | Dump Pet Journal details |
| `/renown` | Show Renown faction info |
| `/friendship` | Show Friendship reputation info |
| `/playerlevel` | Show player level and XP |
| `/charlevel` | Show character effective level and XP |
| `/tradepost` | List TradePost activities |
| `/questinfo <name>` | Look up quest details |
| `/questavailable` | List quests in current zone |
| `/zoneinfo <name>` | Get zone details |
| `/zonelist` | List all continents and zones |
| `/xpdetails` | Show XP and leveling info |
| `/xpsources` | List XP sources (placeholder) |
| `/api <function>` | Call a WoW API function by name |

## Compatibility

- Retail Midnight (Interface 120000, 120001)
- Mists of Pandaria Classic (Interface 50503)
- Cataclysm Classic (Interface 40402)
- Classic Era (Interface 11508)

## Installation

1. Download from [CurseForge](https://www.curseforge.com/wow/addons/dicetools) or [GitHub Releases](https://github.com/donniedice/DiceTools/releases)
2. Extract to your `Interface/AddOns` directory
3. Restart WoW and enable the addon
