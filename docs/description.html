# RGX | DiceTools ## ![](https://github.com/donniedice/SimpleQuestPlates/blob/main/media/kiwi.gif?raw=true) RGX Mods - RealmGX Community Project *** ## 🎯 Overview **DiceTools** is a developer and debugging toolkit for World of Warcraft. Access a suite of slash commands to inspect quests, zones, pets, XP stats, faction reputations, and explore the WoW API. ![RealmGX Kiwi](https://github.com/donniedice/SimpleQuestPlates/blob/main/media/kiwi.gif?raw=true) **The Kiwi Says:** "Need answers? Just ask!" *** ## ✨ Features 🔍 Pet Journal Inspector - Dump full pet stats including health, power, speed, and rarity. ⚡ Quest Tools - Look up quest details by name/ID, list available quests in your zone. 🌍 Zone Explorer - Get zone details by name, list all continents and their zones. 📊 XP & Level Details - Player level, current XP, rested XP, and XP to next level. 🏆 Faction Info - Renown faction levels and friendship reputation status. 🛒 TradePost Tracker - List current TradePost activities and completion status. 🔧 API Explorer - Call any global WoW API function by name and inspect the result. 🗑️ Utility Commands - Reload UI, clear all chat windows, check game version. *** ## 📋 Slash Commands The addon can be managed using the following slash commands:
/dt # List all commands
/info # Show game version
/rl # Reload UI
/clear # Clear all chat windows
/petinfo # Dump Pet Journal details
/renown # Show Renown faction info
/friendship # Show Friendship reputation info
/playerlevel # Show player level and XP
/charlevel # Show character effective level and XP
/tradepost # List TradePost activities
/questinfo <name> # Look up quest details
/questavailable # List quests in current zone
/zoneinfo <name> # Get zone details
/zonelist # List all continents and zones
/xpdetails # Show XP and leveling info
/xpsources # List XP sources (placeholder)
/api <function> # Call a WoW API function by name
